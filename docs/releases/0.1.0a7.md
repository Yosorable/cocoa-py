# 0.1.0a7

The system modules now distribute their inline Python annotations without
duplicated public stub packages. The single-file module layout, public imports,
signatures, typed records and runtime behavior remain unchanged from 0.1.0a6.

## Type information

- Removed the generated `clipboard-stubs`, `device-stubs`, `location-stubs`,
  `motion-stubs` and `share-stubs` packages and `tools/generate_stubs.py`.
  Public type declarations are maintained directly in the `.py` implementations.
- Kept `_cocoa/_system.pyi` as a small internal declaration for the compiled
  native bridge. It does not define a public service API.
- The optional embedded installer removes obsolete companion stub files owned
  by an earlier installation's RECORD, while preserving unrelated files.

Type checkers inspecting the installed single-file modules need to read their
implementations. With mypy, enable `follow_untyped_imports` or run:

```sh
mypy --follow-untyped-imports my_script.py
```

With Pyright, enable `useLibraryCodeForTypes`; strict configurations can set
`reportMissingTypeStubs` to `false`. Parameter validation and result inference
remain covered by positive and negative consumer tests. See
[system module types](../typing.md) for examples and validation commands.

## Distribution

- `cocoa_py-0.1.0a7-cp314-cp314-macosx_14_0_arm64.whl`
- `cocoa_py-0.1.0a7-cp314-cp314-ios_17_0_arm64_iphoneos.whl`
- `cocoa_py-0.1.0a7-cp314-cp314-ios_17_0_arm64_iphonesimulator.whl`
- `cocoa_py-0.1.0a7.tar.gz`

The minimum targets remain macOS 14+ and iOS 17+, with standard GIL-enabled
CPython 3.14. Simulator wheels support Apple Silicon Macs.

## Validation

Release builds use CPython 3.14.6 on Apple Silicon macOS 26.6.2 and Xcode 27.0.
The macOS regression run completed 353 tests: 191 passed and 162 optional or
environment-dependent cases were skipped. Installed-package tests cover inline
type inference, rejection of invalid calls, independent imports and embedded
upgrade cleanup. Each iOS wheel passed all four platform, architecture, linkage,
resource and RECORD validation tests. Source archive and wheel checks confirm
that the removed public stubs and generator are absent.

iOS runtime tests were not repeated for this packaging change. The unchanged
runtime implementations were exercised on iOS 26.5 for
[0.1.0a6](0.1.0a6.md). The minimum supported macOS and iOS versions were not run
separately; physical sensor behavior still requires device checks.
