# 0.1.0a2

This alpha release expands the original Core ML preview into an independent
collection of Apple platform modules: audio, scene, coreml, photos, location,
motion, clipboard, device and share.

## Distribution

The `v0.1.0a2` Git tag identifies the release source. PyPI provides:

- `cocoa_py-0.1.0a2-cp314-cp314-macosx_14_0_arm64.whl`
- `cocoa_py-0.1.0a2-cp314-cp314-ios_17_0_arm64_iphoneos.whl`
- `cocoa_py-0.1.0a2.tar.gz`

Both wheels target standard CPython 3.14 with the GIL. The macOS wheel targets
Apple Silicon and includes the permission launcher. The iPhoneOS wheel targets
arm64 devices and includes precompiled scene shaders and the SDK privacy
manifest. NumPy is optional except for Core ML and explicit array helpers.

Public imports stay top-level. Six private native extensions and shared Python
helpers live under `_cocoa/`, with independent loading and resource lifecycles;
the public Core ML extension remains top-level. Hosts install the iOS wheel at
build time and package its extensions with CPython's normal framework loader.

Release versions, Git tags and wheel SHA-256 hashes provide artifact provenance.
The distribution does not include a custom `build.json` file. Optional file
access callbacks support host-managed security-scoped bookmarks without linking
against host-specific symbols.

## Validation scope

The regression suite exercises real macOS audio rendering, Core ML inference,
Box2D physics, Metal readback, system requests, the launcher, independent imports,
host callbacks and embedded upgrades. iPhoneOS artifact checks cover binary
architecture, deployment target, Python linkage, entry points, resources and
wheel RECORD hashes. Host integration is also checked with Debug and Release
iPhoneOS builds.

Minimum macOS 14 hardware, Intel Macs, iPhone permissions, microphone/sensor
behavior, Photos selection and audio route changes are not implied by these
checks. No simulator execution is part of this release's validation.

See the [API guide](../api.md), [macOS guide](../macos.md) and
[iOS embedding guide](../embedding.md) for usage and platform differences.
