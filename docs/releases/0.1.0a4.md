# 0.1.0a4

This alpha release expands the system modules and adds scene controls, native
text editing and image capture. Public imports remain top-level and independent;
existing hosts continue to consume a versioned wheel at build time.

## System modules

- Clipboard operations use a typed binary bridge and support URLs, images,
  multiple representations, content-state queries, local-only writes and iOS
  expiration. [Clipboard](../clipboard.md) describes platform differences.
- Sharing accepts Pillow images, encoded image buffers and named in-memory
  attachments. Temporary files and file-access tokens remain valid through
  presentation, cancellation or service completion, then are cleaned up.
  See [Sharing](../sharing.md).
- Location adds fresh-sample controls, magnetic and true-north compass readings,
  bounded heading streams and explicit orientation selection. Batched fixes,
  permissions and request cleanup are covered by native regressions.
  [Location](../location.md) documents the foreground service boundary.
- Motion shares native sampling between subscribers while preserving independent
  queues and delivery intervals. Device-motion streams expose reference frames
  and magnetic calibration status, and reject conflicting frame requests without
  disrupting an existing stream. See [Motion](../motion.md).
- Native request waits avoid redundant wakeups. macOS battery reporting handles
  charging that is paused by the operating system.

## Scene

- [Image capture](../scene-capture.md) exports scenes and nodes to images or
  in-memory buffers with explicit resource cleanup.
- [Text input](../scene-text-input.md) provides native editors and reusable input
  sessions on iOS and macOS.
- [Scene UI](../scene-ui.md) adds controls, scrolling, clipping, focus navigation,
  screen overlays and input events.
- Path tessellation accounts for rendering resolution.

The optional macOS launcher remains available for interpreters that lack an
application identity or permission usage descriptions. Ordinary
`python script.py` remains the default execution path.

## Distribution and validation

The `v0.1.0a4` Git tag identifies the release source. Distribution files are:

- `cocoa_py-0.1.0a4-cp314-cp314-macosx_14_0_arm64.whl`
- `cocoa_py-0.1.0a4-cp314-cp314-ios_17_0_arm64_iphoneos.whl`
- `cocoa_py-0.1.0a4.tar.gz`

Requirements remain Apple Silicon macOS 14+ or arm64 iOS 17+, with standard
GIL-enabled CPython 3.14. NumPy and Pillow are optional runtime extras.

Release validation uses CPython 3.14 on Apple Silicon macOS 26.6.2, including
native audio, Core ML, Box2D, desktop Metal, text editing, sharing and system
request regressions. Artifact checks inspect both wheel platforms, deployment
targets, resources and RECORD hashes, together with source archive contents.

Development builds of the clipboard, sharing, location and motion
changes were separately exercised on a physical iPhone. Those results cover
their individual smoke scripts; they are not a claim that the final release
wheel has been tested on every supported OS. Audio routes, absolute sensor
accuracy and actual delivery to a sharing service retain
their documented validation limits. No simulator validation is claimed.
