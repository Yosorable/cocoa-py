# 0.1.0a10

This release fixes cached Scene layers under nonuniform scale, shear and
reflection, including clipped content and image capture.

## Scene

- Cached `Layer` textures retain the full affine transform in both native and
  Python drawing. Clipping and hit testing follow the same geometry, including
  nested layers. Changing a layer's own transform does not require invalidation.
- Mirroring preserves asymmetric content and can reuse the local cache.
  Singular transforms draw no content and recover when the transform changes.
- Image capture chooses intermediate layer resolution separately for each
  local axis. A compressed axis no longer inherits the enlarged axis's pixel
  density, including inside nested layers and captures with nonuniform output
  resolution.
- Temporary capture textures reduce raster resolution when extreme shear
  would exceed the texture dimension or pixel limits, while preserving the
  full affine transform, placement and clipping. Live caches and renderer
  state are restored after successful capture or allocation failure.

See [image capture](../scene-capture.md) for allocation limits and the
[API guide](../api.md) for layer invalidation rules.

CPython 3.14. The simulator wheel targets Apple Silicon Macs.

## Validation

The macOS release wheel was tested in a fresh virtual environment with standard
CPython 3.14.6, NumPy 2.5.4 and Pillow 12.3.0 on Apple Silicon macOS 26.6.2,
using Xcode 27.0. With desktop UI enabled, 460 tests completed: 454 passed and
six were skipped. The passing tests include cached-layer affine geometry,
anisotropic and nested capture, clipping, hit testing, allocation failure
cleanup, Metal readback, Core ML inference and live audio playback.

Three skips require an iOS artifact and are covered separately by the iOS wheel
checks. The network geocoder test remained disabled, and the optional mypy and
pyright consumer checks were not installed in this environment.

All release wheels were built from clean source-distribution extractions;
their runtime sources were verified against the final archive. Each iOS wheel
passed all four platform, architecture, linkage, shader, resource and RECORD
checks.
The declared minimum OS versions and physical-device runtime behavior were not
tested separately for this release.
