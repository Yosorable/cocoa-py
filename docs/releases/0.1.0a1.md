# 0.1.0a1 发布验证

## 范围

首次预发布仅提供顶层 `coreml` 原生扩展。App 中现有的 CoreML 实现被原样用于独立构建，
未包含 Pythona 的其他源码或运行时。此版本尚未完成其他模块迁移或 iOS 宿主接入。

## 已完成检查

- 在 macOS 26.6.2、Apple Silicon、标准 CPython 3.14 上构建源码包和 wheel。
- 使用 setuptools 84.0.0、NumPy 2.5.3 在隔离构建环境中构建。
- 从生成的源码包构建 wheel，确认源码包包含原生头文件和测试模型。
- 在独立虚拟环境中安装 wheel，确认 `coreml` 来自虚拟环境的 site-packages。
- 9 项公开 API 回归全部通过：实际 Core ML 模型编译与推理、RGB/RGBA、灰度与 Float16、
  非连续数组、批量推理、模型描述、路径及非法参数。
- wheel 不包含内部测试专用接口。
- `twine check --strict` 对两个发布文件均通过。
- `vtool` 确认原生扩展最低部署版本为 macOS 14.0；`otool` 确认只链接 Apple 系统库。
- 没有运行模拟器；最低 macOS 版本尚未在独立旧系统上执行验证。

## 正式发布结果

已于 2026-09-12（UTC+8）成功发布到正式 PyPI，维护者为 `Yosorable`：
[cocoa-py 0.1.0a1](https://pypi.org/project/cocoa-py/0.1.0a1/)。

- PyPI 接受了源码包和 macOS ARM64 wheel，确认 `cocoa-py` 项目已实际创建。
- 从 PyPI 下载两个文件，下载内容、PyPI JSON 元数据及本地文件的 SHA-256 全部一致。
- 在另一个全新虚拟环境中，通过正式 PyPI 安装 `cocoa-py[coreml]==0.1.0a1`，
  并确认 `coreml` 原生扩展和 NumPy 2.5.3 可以成功导入，版本及公开 API 正确。
- GitHub 远程仓库尚由维护者另行创建，本地仓库未设置远程地址。

发布使用 `twine upload --config-file ~/.pypirc --repository pypi`。
Twine 7 的 `--repository-url` 会跳过 `.pypirc` 中的账号配置，不应与这里的读取方式混用。
发布凭据位于用户目录的 `~/.pypirc`，未进入 Git 或任何发布文件。
