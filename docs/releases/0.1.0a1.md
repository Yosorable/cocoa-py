# 0.1.0a1 发布验证

## 范围

首次预发布仅提供顶层 `coreml` 原生扩展。App 中现有的 CoreML 实现被原样用于独立构建，
未包含 Pythona 的其他源码或运行时。此版本尚未完成其他模块迁移或 iOS 宿主接入。

## 已完成检查

- 在 macOS 26.6.2、Apple Silicon、标准 CPython 3.14 上构建源码包和 wheel。
- 使用 setuptools 84.0.0、NumPy 2.5.3 在隔离构建环境中构建。
- 从生成的源码包构建 wheel，确认源码包包含原生头文件和测试模型。
- 在独立虚拟环境中安装 wheel，确认 `coreml` 来自虚拟环境的 site-packages。
- 9 项公开 API 回归全部通过：实际 Core ML 模型编译与推理、RGB/RGBA、灰度与 Float16、
  非连续数组、批量推理、模型描述、路径及非法参数。
- wheel 不包含内部测试专用接口。
- `twine check --strict` 对两个发布文件均通过。
- `vtool` 确认原生扩展最低部署版本为 macOS 14.0；`otool` 确认只链接 Apple 系统库。
- 没有运行模拟器；最低 macOS 版本尚未在独立旧系统上执行验证。
